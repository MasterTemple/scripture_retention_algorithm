This algorithm is a modified version of the "Scripture Memorization and Meditation System" used by Tom Frost at [Foundation for Reasonable Christianity](https://www.reasonablechristianity.org/).

The modifications are primarily in considering a "month" as a 4-week interval from the start-date, and completely ignoring the Gregorian Calendar.

The methodology is simple, for each verse that you have memorized, repeat it:
1. Once a day, every day, for 7 weeks
2. Once a week, every week, for 7 months
3. Once a month, every month, for 7 year

When saying reciting it, you will say out-loud:
1. The topic
2. The verse reference
3. The verse content

Note: this is not performed in order to memorize a verse, but to retain a verse you have already memorized, and to foster meditation on it.

It is designed that you would add 1 verse each week.
Doing it at this rate will result in reciting 23 verses each day, but that is after you have completely filled the moving window of daily, weekly, and monthly verses (which takes 7 years to build up to).
At that point, it will be a very manageable 5-10 minute activity each day.

You are free to add as many verses as you would like per week, however it is encouraged that you prioritize maintaining and reviewing previous verses, rather than memorizing more and more, lest in you forget what you have worked towards.
